Cum se antrenează

  1. Exportă JSON-ul cu mostre (butonul de mai sus).
  2. Importă-le ca secvențe de landmarks:
    python -m ml.import_recordings --input semnai-samples.json
  3. Antrenează (alfabet + semnele tale):
    python -m ml.train --train-root data/asl/train --val-root data/asl/val --out-dir checkpoints
  4. Exportă pentru browser:
    python -m ml.export_onnx --checkpoint checkpoints/best.pt
  5. Apasă „Reîncarcă modelul”.

model & ajutor

Ce rulează, de fapt, în browser.

Două rețele independente: MediaPipe HandLandmarker găsește mâna, iar clasificatorul SemnAI (LSTM) transformă secvența de 30 de cadre în semn. Totul local, în WebAssembly.

Pipeline

  1. Cadru videocamera locală, 30 fps
  2. 21 landmarksMediaPipe HandLandmarker, 2 mâini
  3. Normalizaretranslație după pumn, scalare după palmă
  4. Fereastră 30×126aproximativ o secundă de context
  5. LSTM + softmaxONNX Runtime Web, WASM
  6. Netezire + praglitera se fixează doar când e stabilă
  7. VoceWeb Speech API, voce română

Comenzi utile

python -m ml.server                 # pornește site-ul
python -m ml.import_asl_letters     # dataset ASL -> landmarks
python -m ml.import_recordings --input semnai-samples.json
python -m ml.train --train-root data/asl/train \
    --val-root data/asl/val --out-dir checkpoints
python -m ml.evaluate --checkpoint checkpoints/best.pt \
    --root data/asl/val
python -m ml.export_onnx --checkpoint checkpoints/best.pt
python -m ml.classify --checkpoint checkpoints/best.pt

Rulează din rădăcina proiectului, cu venv-ul activat.

Limite cunoscute

  • Modelul livrat este antrenat pe alfabetul ASL (A–Z), semne statice. Literele J și Z sunt dinamice, deci sunt cele mai fragile.
  • Iluminarea slabă, mănușile și mâinile parțial ieșite din cadru scad acuratețea — modelul vede doar scheletul, nu textura.
  • Nu este un traducător de propoziții: recunoaște semne izolate, literă cu literă, și le lipește în text.
  • Vocea depinde de vocile instalate în sistem; fără voce românească se folosește cea implicită.
